   2) Implementing Requirements
This table should serve as a draft for how you will implement the requirements into your final project. You may change your ideas later on, but your final site must fulfill all the requirements.

Requirement	Implementation
Purpose/Functionality

A 1-2 sentence description of the purpose or functionality of your site	The Student Assignment Tracker will help students organize school assignments in one place. Users will be able to add assignments, select their classes, enter due dates, view upcoming work, and track completed assignments.
State Dataclass Attributes
 
Minimum of 4 attributes, one of which must be a list/dict of instances of your second dataclass.

Briefly describe each attribute, its type, and how it will be meaningfully modified throughout the site.	1. assignments: list[Assignment] stores all assignment objects. The list changes when users add assignments or update completion status. 
2. assignment_name: str stores the name entered by the user. It updates when the user enters a new assignment name. 
3. assignment_course: str stores the selected class. It updates when the user selects a class. 
4. assignment_due_date: str stores the due date entered by the user. It updates when the user enters a date. 
5. filter_course: str stores the selected class filter. It updates when users choose a class to view.
Second Dataclass

Your second dataclass, including its attributes, their types, and how they will be meaningfully modified (if they are modified)	Assignment will represent an individual school assignment. Its attributes are 
name: str, the assignment name
course: str, the class it belongs to
due_date: str, its due date
completed: bool, whether the assignment is finished. 
The completion field changes when the user marks an assignment as completed.
Routes (minimum 7) 

The names of your route functions	1. index() displays the home page. 
2. add_assignment() displays the assignment form. 
3. submit_assignment() saves a new assignment. 
4. all_assignments() displays every assignment. 
5. upcoming_assignments() displays unfinished assignments and their due dates. 
6. completed_assignments() displays completed assignments. 
7. classes() displays the class filter. 
8. filter_by_class(course) displays assignments for the selected class. 
9. mark_completed(index) updates an assignment's completion status. 
10. about() displays information about the website.
Pages (minimum 5)

A brief description of the pages in your site	1. Home: Main navigation page. 
2. Add Assignment: Form for entering assignment information. 
3. All Assignments: Displays every saved assignment. 
4. Upcoming Assignments: Displays unfinished assignments and due dates. 
5. Completed Assignments: Displays finished work. 
6. Classes: Allows users to filter assignments by class. 
7. About: Explains the purpose of the website.
User Input (minimum 3)

Description of user input components (TextBox, TextArea, CheckBox, or SelectBox) and their purposes

For more information on these input types, see Drafter Documentation.
1. TextBox: Allows users to enter an assignment name. 
2. SelectBox: Allows users to select the class for an assignment. 
3. TextBox: Allows users to enter a due date in YYYY-MM-DD format. 
These inputs provide the information needed to create Assignment objects.
If Statements (minimum 3)
Brief description of what will be evaluated in your if statements and how they will meaningfully change the logic of the site	1. Check whether the assignment name, class, and due date are empty before saving. 
2. Check whether an assignment is completed to determine which page should display it. 
3. Check whether the selected class matches an assignment's course when filtering assignments. 
4. Check whether an assignment is unfinished before displaying it on the upcoming assignments page.

This loop must iterate over the list/dict of dataclass instances in your State attribute.
Description of this loop and why it is meaningful to the site	A loop will iterate through the assignments list inside State. It will display each assignment's name, class, due date, and completion status.
