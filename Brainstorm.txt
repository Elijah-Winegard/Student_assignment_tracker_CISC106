I want to create a Student Assignment Tracker. The goal is to help students organize their
schoolwork and keep track of upcoming assignments. Students often have assignments
from multiple classes, so I want to create one website where they can enter assignments,
view due dates, and track their progress.
2. Prior Implementations: Search the internet. What existing tools or websites
currently attempt to address it?
There are already some websites that help students organize their school work. Some
examples are: MyStudentLife, Todoist, Google Calendar. My website will focus on being a
simple assignment tracker without any complicated features that can take away from user
experience.
3. Your Implementation: Briefly describe the legitimate purpose or functionality of
your site. How would you want this web application to be used?
My website will allow students to add assignments, select the class for each assignment,
enter due dates, and mark assignments as completed. Students will also have separate
pages to view all assignments, upcoming assignments, and completed work. The purpose is
to make organizing schoolwork easier.
Part 2: The Input-Process-Output (IPO) Model
Think about the fundamental flow of your program.
1. The Core Goal: Every program has three main phases: taking input, processing
data, and presenting output. In one sentence, what is the ultimate goal your
program will accomplish for the user? Be specific and use CS1 concepts.
The goal of my program is to collect assignment information from students, store
assignments in a list of objects, organize them by class and due date, and display their
progress.
2. Input: What specific information will the user need to provide to your program?
(e.g., a city name, a numerical budget, a list of hobbies).
Users will provide: Assignment name using a TextBox, Class name using a SelectBox, Due
date using a TextBox, Additional assignment details using a TextArea, Completion status
using a CheckBox.
3. Processing: At a high level, how will the computer manipulate or evaluate that
data? (e.g., calculate the average, filter out options that are too expensive,
compare the input against a database).
The program will store each assignment as an object inside a list. It will use loops to display
assignments and if statements to check whether assignments are completed or upcoming.
Users will also be able to filter assignments by class.
4. Output: What will the user get back? (e.g., a recommendation, a calculated
safety factor, a formatted schedule).
The website will display: A list of all assignments, Upcoming assignments, Completed
assignments, Assignments organized by class, A summary of how many assignments are
completed and unfinished.
